# Reporting a security vulnerability

Report suspected DotAIOS vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/filocosta46/dotaios/security/advisories/new).
You can also open the repository's Security and quality tab, choose Advisories,
and select **Report a vulnerability**. Reports are private to you and the maintainers
and collaborators invited to the advisory.

Do not post vulnerability details in a public issue or pull request. If the
private reporting form is unavailable, open an issue only to request that
private vulnerability reporting be enabled. Do not include the vulnerability
details in that request.

Include the affected DotAIOS version, operating system, security impact, and
minimal steps to reproduce with synthetic or redacted data. Do not send
credentials, tokens, private context, captured conversations, or personal local
paths, even in a private report.

For the product's storage, permission, and integration boundaries, read the
[security guide](docs/security.md).

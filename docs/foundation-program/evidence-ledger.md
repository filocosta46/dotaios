## Evidence discipline

- A passing test proves only the behavior named by the test and the environment it ran in.
- A configured bridge, adapter, or skill is not supported until a fresh host discovers it and produces the expected observable result.
- An empty agent report is not clean evidence; every research or review receipt must expose failures and coverage.
- Derived metadata is rebuildable evidence, never the only durable copy of user knowledge.
- A stale local tracking ref is not remote topology evidence; compare the live remote before reasoning about ahead/behind state.

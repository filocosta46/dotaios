## Question

Which observable continuity jobs must the free Foundation promise to the non-expert knowledge worker, and what evidence distinguishes a reliable outcome from a file merely existing?

## Proposed resolution

For a selected project and explicit current task, DotAIOS surfaces one smallest relevant README-body evidence window by default, shows its AIOS-relative source and original line range, accounts for selection and budget omissions, and preserves the existing bounded context and privacy guardrails.

The core verdict proves evidence availability without an LLM judge.
Host support additionally requires a produced-result receipt.

The exact privacy and input contract is recorded in `docs/plans/2026-08-09-001-feat-foundation-continuity-plan.md` and remains blocked on user approval.

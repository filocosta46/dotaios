## Question

What core files, bridge behavior, skill discovery, permissions, support tiers, and observable receipts must a host satisfy before DotAIOS may claim that a fresh agent can continue the user's work?

## Proposed resolution

Configured, discoverable, invoked, and produced remain separate support states.
The first continuity receipt uses Codex on the iMac, an isolated temporary Codex home, the local stdio MCP configuration, and a JSON event stream that proves a completed `read_working_context` call before exact evidence and source markers are accepted.

Other hosts remain documented compatibility tiers until each produces its own native receipt.

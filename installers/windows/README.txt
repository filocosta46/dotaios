DotAIOS for Windows
====================

After installation, open your Start Menu and click "Set up DotAIOS".

If you have not installed Node.js yet, the setup script will open the
Node.js download page for you. Install the LTS version, then click
"Set up DotAIOS" again.

What gets created:
  - A folder at  %USERPROFILE%\aios
  - Bridge files for Claude Code, Codex, and Gemini

Nothing is uploaded. Everything stays on your computer.

To update DotAIOS later, the setup script always pulls the latest
version via npx, so re-running "Set up DotAIOS" upgrades automatically.

Need help?  https://github.com/filocosta46/dotaios/issues

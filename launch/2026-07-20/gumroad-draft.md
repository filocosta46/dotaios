A practical set of workflows for independent consultants who use an AI client but do not want to build a memory system from scratch. It fits inside DotAIOS, the free local folder that keeps your working context organized for the AI tools you already use.

### What you are buying

The free DotAIOS core gives your AI work a clear home for context, projects, memory, sources and skills. This paid pack adds a curated consultant setup on top of that core.

Planned contents, subject to final release verification:

- A consultant workspace template with clear places for client context and active work.
- Reviewed workflows for research, meeting preparation, follow-up, proposals and delivery.
- Setup instructions written for people who do not want to maintain an agent system.
- A versioned package, changelog, removal guide and recovery guide.

This pack does not include an AI subscription. It does not replace Codex, Claude or another compatible AI client. It gives those tools a more organized context folder to work with.

### Requirements

Before buying, you will need:

- A Mac, Windows or Linux computer covered by the compatibility table on the final product page.
- A compatible AI client and any subscription that client requires.
- Permission to let that client read the folders you choose.
- A backup of any existing DotAIOS folder before installation.

The final listing must name the tested operating systems, clients and versions. If a client is not listed, compatibility is not promised.

DotAIOS is built around files on your computer. The pack does not include hosted storage or automatic cloud mirroring.

The pack must request only the file permissions it needs. It must not collect analytics, telemetry or document contents unless a future version asks for separate, informed consent.

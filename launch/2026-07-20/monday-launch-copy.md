## Founder announcement draft, English

I kept running into the same problem with AI tools: the model was capable, but my context was scattered across folders, notes and old chats.

So I built DotAIOS.

DotAIOS is a local folder that organizes the context an AI client needs to work with you. Projects, memory, sources and reusable skills have a clear place. You keep the files and choose which client can read them.

It does not replace Codex, Claude or another AI client. It helps the tool you already use understand your work without asking you to invent a memory system first.

The core is free. I am starting with independent consultants and freelancers because their work is full of context switching, client files and repeated tasks.
